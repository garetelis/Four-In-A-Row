# Four-In-A-Row
This is a file to run in VS Code or any other Java compiler that allows you to play the classic game Connect Fo... I mean Four In A Row.

Try it out!

With code: https://codehs.com/sandbox/garrettellis/new-sandbox-program-3

Without code: https://codehs.com/sandbox/garrettellis/new-sandbox-program-3/run

This demo runs in your browser so no need to install anything fancy, just click in and play!

Jump right into the game by choosing which of the seven columns to drop your piece! Needs two people to play.

If using the .zip file in the release just download, unzip, and run directly from the file or else it will not work.

You can also of course just download the .java file and run it directly from VS Code. (esiest way)
